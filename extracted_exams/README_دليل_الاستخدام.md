## 🚀 خطوات الاستخراج والاستيراد إلى الموقع:

1. **الاستخراج بالذكاء الاصطناعي**:
   - افتح أداة **Antigravity** أو أي نموذج ذكاء اصطناعي.
   - أرسل صور أوراق الاختبار مع نسخ البرومبت الموجود في:  
     `PROMPT_البرومبت_للاستخراج.md`.
   - سيقوم الذكاء الاصطناعي باستخراج الأسئلة والإجابات والتعليلات وتنسيقها في كود JSON مطابق.

2. **حفظ الملف في المجلد المناسب**:
   - احفظ الملف باسم واضح، مثلاً:  
     `نموذج_1.json` أو `نموذج_دور_أول.json`.
   - ضعه داخل مجلد المادة والعام المناسب (مثال: `02_الثالث_الثانوي_علمي/08_الكيمياء/عام_2023_2024/نماذج_وزارية_نهائية/نموذج_1.json`).

3. **الاستيراد في لوحة التحكم (Admin Web)**:
   - ادخل إلى لوحة التحكم عبر المتصفح: `https://yemen-exam-admin.web.app`.
   - اختر من القائمة الجانبية: **بنك الاختبارات المؤتمتة**.
   - حدد المرحلة والمادة والعام الدراسي، ثم اضغط على زر **استيراد الأسئلة (JSON)**.
   - ارفع الملف أو الصق محتوى الـ JSON واضغط **حفظ** ليتم إدراج الاختبار فوراً لجميع الطلاب!
