# 📋 البرومبت المعتمد لاستخراج نماذج الاختبارات الوزارية من الصور بدقة 100%

> **طريقة الاستخدام:**  
> 1. افتح مشروع مجلد `extracted_exams` في جهازك بواسطة أداة الذكاء الاصطناعي (مثل **Antigravity** أو **Claude** أو **Gemini**).  
> 2. أرفق صور ورقة النموذج الوزاري (صفحة أو عدة صفحات).  
> 3. انسخ هذا البرومبت بالكامل وضعه في الدردشة مع الصور.  
> 4. سيقوم الذكاء الاصطناعي باستخراج الأسئلة كاملة وتوليد ملف JSON مطابق تماماً لنظام منصة اختبارات اليمن.

---

## 📌 نص البرومبت (انسخه وضعه مع صور الاختبار):

```text
أنت خبير معتمد في تدقيق واستخراج أسئلة الامتحانات الوزارية المؤتمتة في الجمهورية اليمنية.
مهمتك: قراءة صور ورقة الاختبار الوزاري المرفقة بدقة تامة، واستخراج جميع الأسئلة وتحويلها إلى ملف مصفوفة JSON معتمد لمنصة اختبارات اليمن.

قواعد الاستخراج الإلزامية:
1. استخرج كافة الأسئلة بالترتيب والتسلسل الدقيق الموجود في ورقة الاختبار دون تخطي أي سؤال.
2. أنواع الأسئلة:
   - لأسئلة الصواب والخطأ (ضع علامة صح أو خطأ):
     * اجعل "type": "trueFalse"
     * الخيارات دائماً: "options": ["صح", "خطأ"]
     * إذا كانت الإجابة صحيحة، اجعل "correctAnswerIndex": 0
     * إذا كانت الإجابة خاطئة، اجعل "correctAnswerIndex": 1
   - لأسئلة الاختيار من متعدد:
     * اجعل "type": "mcq"
     * الخيارات: "options": [الخيار الأول, الخيار الثاني, الخيار الثالث, الخيار الرابع]
     * رقم الإجابة الصحيحة يبدأ من 0 (أي: الخيار 1 = 0، الخيار 2 = 1، الخيار 3 = 2، الخيار 4 = 3).
3. نص السؤال والخيارات:
   - انقل النص العربي بدقة مع علامات الترقيم والتشكيل إن وجد.
   - إذا كان هناك معادلات رياضية أو رموز كيميائية، اكتبها بصيغة LaTeX داخل علامات $ مثل: $x^2 + 5x$ أو $H_2SO_4$.
4. أضف تعليلاً أو توضيحاً موجزاً ومفيداً في حقل "explanation" يشرح سبب صحة الإجابة أو يوضح القاعدة من الكتاب المدرسي.
5. أخرج النتيجة فقط كمصفوفة JSON صالحة ونقية 100% بدون أي نصوص قبلها أو بعدها.

هيكل الـ JSON المطلوب لكل سؤال:
[
  {
    "questionNumber": 1,
    "type": "trueFalse",
    "text": "نص السؤال هنا بدقة",
    "options": ["صح", "خطأ"],
    "correctAnswerIndex": 0,
    "explanation": "شرح توضيحي ومختصر لسبب الإجابة"
  },
  {
    "questionNumber": 2,
    "type": "mcq",
    "text": "نص السؤال الاختياري هنا",
    "options": [
      "الخيار الأول",
      "الخيار الثاني",
      "الخيار الثالث",
      "الخيار الرابع"
    ],
    "correctAnswerIndex": 1,
    "explanation": "توضيح الإجابة وقاعدتها من المنهج"
  }
]
```
